## Обзор

Shelter — это свободное приложение с открытым исходным кодом (FOSS), использующее системную функцию «Рабочий профиль» Android для создания полностью изолированной песочницы, в которую можно устанавливать, клонировать и изолировать приложения.

Этот форк адаптирован для современных версий Android (включая Android 16 / API 36) и устройств Pixel. В приложение интегрирован современный интерфейс Material 3 на карточной основе, системные плитки быстрых настроек, нативный Photo Picker и двусторонний обмен файлами без устаревших оверлеев и опасных разрешений.

## Ключевые особенности

- **Изоляция рабочего профиля**: установка и клонирование приложений в изолированный контейнер, предотвращающий доступ к личным файлам, контактам и данным основного профиля.
- **Плитки быстрых настроек (Quick Settings)**: управление профилем прямо из системной шторки Android — плитки «Заморозить все» и «Рабочий профиль (тихий режим)».
- **Material 3 редизайн**: скруглённые карточки разделов настроек (16dp), современные переключатели `MaterialSwitch` и векторные пиктограммы.
- **Нативный Android Photo Picker**: безопасный выбор фото и видео через изолированный системный пикер Android 13+ с мгновенной отправкой в нужный профиль.
- **Двусторонний обмен файлами**: кросс-профильные фильтры намерений для системной шторки «Поделиться» (`ACTION_SEND`) и проводника вместо устаревшего File Shuttle; удалены опасные разрешения `SYSTEM_ALERT_WINDOW` и `MANAGE_EXTERNAL_STORAGE`.
- **Автоматическая и групповая заморозка**: приостановка фоновых приложений при блокировке экрана или вручную по нажатию плитки/ярлыка.
- **Сквозной интерфейс Android 16**: полная поддержка безрамочного отображения (Edge-to-Edge) и предиктивного жеста «Назад».
- **Оптимизация для Pixel 9a**: аппаратная адаптация разметки, сенсорных зон и энергопотребления под современные OLED-экраны.

## Начало работы

### Требования
- JDK 17 (например, OpenJDK 17 или JBR из состава Android Studio)
- Android SDK с установленной платформой API 36 и build-tools
- Устройство или эмулятор с Android 14, 15 или 16.

### Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Almanex/Shelter-fork.git
   cd Shelter-fork
   ```
2. Соберите отладочный APK:
   ```bash
   ./gradlew assembleDebug
   ```
3. Установите APK на подключенное устройство через ADB:
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

Подробное руководство пользователя доступно в [Руководстве пользователя](GUIDE_RU.md).

## Запуск тестов

Запуск модульных тестов:
```bash
./gradlew test
```

Запуск инструментальных тестов:
```bash
./gradlew connectedAndroidTest
```

## Развертывание

Сборка подписанного релизного пакета:
```bash
./gradlew assembleRelease
```
Скомпилированный файл будет сохранен в `app/build/outputs/apk/release/`.

### Предупреждение Windows Defender SmartScreen
При запуске вспомогательных скриптов сборки на Windows система может отобразить предупреждение SmartScreen:
- Нажмите **Подробнее**
- Нажмите **Выполнить в любом случае**
